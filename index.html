Step 1: Getting Started with Arduino

Follow these basic setup procedures to verify that your Arduino microcontroller is powered up, recognized by your computer, and ready for code uploads.

IDE & Hardware Setup

  1. Connect your Arduino board to your computer using a USB data cable.
  2. Locate the switch on the board (located on the right side of the LED light) and flip it to the UPLOAD position before uploading code.
  3. Launch the Arduino IDE.
  4. Navigate to Tools > Board and select your board type (e.g., Arduino Uno).
  5. Navigate to Tools > Port and choose the corresponding active COM port (e.g., COM3, COM4, or /dev/ttyACM0).
  6. Ensure the Serial Monitor baud rate is set to 9600 baud.

Basic Connection Test

Upload this minimal code to verify basic upload capabilities and Serial communication. 

void setup() {
  Serial.begin(9600);
  while (!Serial) delay(10);
  Serial.println("Arduino Setup Initialized Successfully!");
}

void loop() {
  Serial.println("System operational...");
  delay(1000);
}

Step 2: Testing Motors & Software Polarity Reversal

Because hardware wiring harnesses are prebuilt, if a wheel spins in the opposite direction from what your code expects, do not disconnect wires. Swap the direction control logic directly in C code by reversing HIGH / LOW output states or negating speed values.

Software Motor Direction Reversal Code

C / C++

Drive both wheels simultaneously and configure direction or standby pins: 

// Left Motor Pins
const int IN1 = 5;  // Left motor direction 1
const int IN2 = 6;  // Left motor direction 2
const int ENA = 3;  // Left motor speed PWM

// Right Motor Pins
const int IN3 = 7;  // Right motor direction 1
const int IN4 = 8;  // Right motor direction 2
const int ENB = 11; // Right motor speed PWM

// Motor Driver Enable/Standby Pin
const int STBY = 3; 

void driveBothMotors(int leftSpeed, int rightSpeed) {
  if (leftSpeed >= 0) {
    digitalWrite(IN1, HIGH);
    digitalWrite(IN2, LOW);
  } else {
    digitalWrite(IN1, LOW);
    digitalWrite(IN2, HIGH);
    leftSpeed = -leftSpeed;
  }
  analogWrite(ENA, leftSpeed);

  if (rightSpeed >= 0) {
    digitalWrite(IN3, HIGH);
    digitalWrite(IN4, LOW);
  } else {
    digitalWrite(IN3, LOW);
    digitalWrite(IN4, HIGH);
    rightSpeed = -rightSpeed;
  }
  analogWrite(ENB, rightSpeed);
}

void setup() {
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(ENA, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT); pinMode(ENB, OUTPUT);
  pinMode(STBY, OUTPUT);
  digitalWrite(STBY, HIGH);
}

void loop() {
  driveBothMotors(180, 180); // Both forward
  delay(2000);
  driveBothMotors(0, 0);     // Stop
  delay(1000);
}

Step 3: Testing IMU (MPU6050)

Test your 6-axis MPU6050 Accelerometer and Gyroscope over I2C communication to read real-time motion and orientation data.

Arduino MPU6050 Initialization & Loop Code 

#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>
#include <Wire.h>

Adafruit_MPU6050 mpu;

void setup() {
  Serial.begin(9600);
  while (!Serial) delay(10);

  if (!mpu.begin()) {
    Serial.println("Failed to find MPU6050 chip on board!");
    while (1) { delay(10); }
  }

  Serial.println("MPU6050 IMU Initialized Successfully!");

  mpu.setAccelerometerRange(MPU6050_RANGE_8_G);
  mpu.setGyroRange(MPU6050_RANGE_500_DEG);
  mpu.setFilterBandwidth(MPU6050_BAND_21_HZ);
  delay(100);
}

void loop() {
  sensors_event_t a, g, temp;

  Serial.print("Accel X: "); Serial.print(a.acceleration.x);
  Serial.print(" | Y: "); Serial.print(a.acceleration.y);
  Serial.print(" | Z: "); Serial.println(a.acceleration.z);

Step 4: Testing Obstacle Sensor (Ultrasonic)

Measure distance in centimeters using ultrasonic pulses to detect obstacles and trigger avoidance maneuvers in your code logic.

Ultrasonic Distance Code 

// Complete obstacle threshold test
#define TRIG_PIN 13
#define ECHO_PIN 12
#define MAX_DISTANCE 200
#define OBSTACLE_DISTANCE 18

long getDistance() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long duration = pulseIn(ECHO_PIN, HIGH, 25000);
  if (duration == 0) return MAX_DISTANCE;
  long distance = duration / 58;
  if (distance > MAX_DISTANCE) distance = MAX_DISTANCE;
  return distance;
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

void loop() {
  long distance = getDistance();
  if (distance < OBSTACLE_DISTANCE) {
    Serial.println("OBSTACLE - STOP");
  } else {
    Serial.println("CLEAR - MOVE");
  }
  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");
  delay(100);
}
