Step 1: Getting Started with Arduino

Follow these basic setup procedures to verify that your Arduino microcontroller is powered up, recognized by your computer, and ready for code uploads.

IDE & Hardware Setup

  1. Connect your Arduino board to your computer using a USB data cable.
  2. Launch the Arduino IDE.
  3. Navigate to Tools > Board and select your board type (e.g., Arduino Uno or Arduino Mega).
  4. Navigate to Tools > Port and choose the corresponding active COM port (e.g., COM3, COM4, or /dev/ttyACM0).
  5. Ensure the Serial Monitor baud rate is set to 9600 baud.

Basic Connection Test

Upload this minimal code to verify basic upload capabilities and Serial communication. 

void setup() {
  Serial.begin(9600);
  while (!Serial) delay(10);
  Serial.println("Arduino Setup Initialized Successfully!");
}

void loop() {
  Serial.println("System operational...");
  delay(1000);
}
Next Steps: Once basic serial upload is verified, proceed to Motor Testing to check direction logic, or access the Troubleshooting Bot if the board isn't turning on or connecting.

Step 2: Testing Motors & Software Polarity Reversal

Because hardware wiring harnesses are prebuilt, if a wheel spins in the opposite direction from what your code expects, do not disconnect wires. Swap the direction control logic directly in C code by reversing HIGH / LOW output states or negating speed values.

Software Motor Direction Reversal Code

C / C++

Use a boolean flag or helper functions to handle motor polarity directly in code: 

// Motor Control Pins
const int IN1 = 5;
const int IN2 = 6;
const int ENA = 3;

// Set true if the left wheel spins backwards
bool reverseLeftMotor = true; 

void driveLeftMotor(int speedPWM) {
  if (!reverseLeftMotor) {
    // Normal direction logic
    digitalWrite(IN1, HIGH);
    digitalWrite(IN2, LOW);
  } else {
    // Software polarity flip (reverses rotation)
    digitalWrite(IN1, LOW);
    digitalWrite(IN2, HIGH);
  }
  analogWrite(ENA, speedPWM);
}

void setup() {
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(ENA, OUTPUT);
}

void loop() {
  driveLeftMotor(180); // Wheel turns forward!
}

Step 3: Testing IMU (MPU6050)

Test your 6-axis MPU6050 Accelerometer and Gyroscope over I2C communication to read real-time motion and orientation data.

Arduino MPU6050 Initialization & Loop Code 

#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>
#include <Wire.h>

Adafruit_MPU6050 mpu;

void setup() {
  Serial.begin(9600);
  while (!Serial) delay(10);

  if (!mpu.begin()) {
    Serial.println("Failed to find MPU6050 chip on board!");
    while (1) { delay(10); }
  }

  Serial.println("MPU6050 IMU Initialized Successfully!");

  mpu.setAccelerometerRange(MPU6050_RANGE_8_G);
  mpu.setGyroRange(MPU6050_RANGE_500_DEG);
  mpu.setFilterBandwidth(MPU6050_BAND_21_HZ);
  delay(100);
}

void loop() {
  sensors_event_t a, g, temp;
  mpu.getEvent(&a, &g, &temp);

  Serial.print("Accel X: "); Serial.print(a.acceleration.x);
  Serial.print(" | Y: "); Serial.print(a.acceleration.y);
  Serial.print(" | Z: "); Serial.println(a.acceleration.z);

  Serial.print(" || Gyro X: "); Serial.print(g.gyro.x);
  Serial.print(" | Y: "); Serial.print(g.gyro.y);
  Serial.print(" | Z: "); Serial.println(g.gyro.z);

  delay(100);
}

Step 4: Testing Obstacle Sensor (Ultrasonic)

Measure distance in centimeters using ultrasonic pulses to detect obstacles and trigger avoidance maneuvers in your code logic.

Ultrasonic Distance Code 

const int TRIG_PIN = A1;
const int ECHO_PIN = A2;
const float OBSTACLE_LIMIT_CM = 15.0;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

float readDistanceCM() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  long duration = pulseIn(ECHO_PIN, HIGH, 30000);
  if (duration == 0) return 999.0;
  return duration * 0.0343 / 2.0;
}

void loop() {
  float dist = readDistanceCM();
  Serial.print("Distance: ");
  Serial.print(dist);
  Serial.println(" cm");

  if (dist < OBSTACLE_LIMIT_CM) {
    Serial.println("WARNING: Obstacle Detected!");
  }
  delay(100);
}
